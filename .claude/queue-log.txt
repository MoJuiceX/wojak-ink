Found and fixed **2 bugs** in the recently changed files:

**File:** `functions/api/combat/fighter-detail.ts:35-37`
**Issue:** The API was querying `did_display_names WHERE did = ?` but this table doesn't exist. The correct table is `did_profiles` with column `did_id`.
**Impact:** Fighter detail modal would fail to show owner names.

### Bug 2: Wrong nftId format in NFTInfoCard Combat tab
**File:** `src/components/gallery/NFTInfoCard.tsx:610`
**Issue:** Was passing `nft.id` (format: "wojak-123") to `FighterStatsPanel`, but the API expects a launcher_id (blockchain NFT ID). Since "wojak-123" is truthy, it wouldn't fall back to the edition number.
**Impact:** Combat tab in the NFT Explorer would never find fighter data.

Both fixes have been committed and pushed to main.
