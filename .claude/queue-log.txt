## Summary

**File:** `functions/api/friends.ts:40`

The GET endpoint was returning all friends regardless of status (pending/accepted/blocked). Since migration 074 added the `status` column for the friend request workflow, the endpoint needed to filter by `status = 'accepted'` to avoid showing pending or blocked friends in friend lists.

**Fix:** Added `AND status = 'accepted'` to the SQL query.

**File:** `src/components/Account/FriendsWidget.tsx:28`

The error detection logic was:
```ts
const error = profilesLoaded && friendProfiles.length === 0 && !isLoading;
```

**Fix:** Changed the condition to only show error when the user has friend IDs but their profiles failed to load:
```ts
const error = profilesLoaded && friendIds.length > 0 && friendProfiles.length === 0 && !isLoading;
```
